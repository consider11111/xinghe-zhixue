# 星河智学 · 高中个性化教学平台

## 直接启动（无需安装或配置数据库）

需要 JDK 17 或更高版本。在 IDEA 中以 Maven 项目打开本目录，等待依赖下载完成，运行 XingheZhixueApplication，访问 http://localhost:8090/ 。无需提前建库、建表或导入数据。

也可以运行以下命令打包，把 jar 复制到其他安装了 JDK 17+ 的电脑运行：

```shell
mvn clean package
java -jar target/xinghe-zhixue-1.0.0.jar
```

默认只初始化三个账号，密码均为 123456：

| 账号 | 身份 |
| --- | --- |
| student | 学生 |
| teacher | 老师 |
| admin | 管理员 |

默认使用随程序提供的 H2 内存存储，不连接本机 MySQL。三个角色都可直接登录，管理后台可查看账号、维护基础资料和检查运行状态。注册界面始终开放。体验模式下提交注册会正常提示“本次注册未保存”，不会新增可登录账号，也不会自动登录；所有修改只在本次运行期间有效，重启后恢复三个初始账号和初始数据。

## 接入 MySQL（保存数据、增加账号）

创建一个空数据库，例如 xinghe_zhixue（UTF-8），并提供有建表、查询和写入权限的数据库账号。启动前配置下面三个环境变量，或在 IDEA 运行配置的环境变量中填写：

```powershell
$env:XINGHE_DB_URL='jdbc:mysql://localhost:3306/xinghe_zhixue?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai'
$env:XINGHE_DB_USERNAME='你的数据库用户名'
$env:XINGHE_DB_PASSWORD='你的数据库密码'
java -jar target/xinghe-zhixue-1.0.0.jar
```

程序会自动建表并补齐三个初始账号，不覆盖已有账号或密码，也不会恢复已删除的账号。注册的账号直接保存到数据库并可登录，管理员也可以新增账号，修改持久保存到 MySQL。首次正式使用时请通过管理后台修改初始密码。体验模式的数据不会自动迁移到 MySQL。

每次启动会检测配置的数据库连接，连接失败时自动使用内存体验模式，三个初始账号仍可登录。数据库恢复或修改连接配置后，需要重启程序重新检测；运行期间不会自动切换数据源或迁移账号。数据库已连接但建表权限不足、表结构不兼容时，需要先修复数据库配置。

## 班级训练与账号管理

默认学生属于高一（3）班，默认老师管理高一（3）班和高一（5）班。管理员可在账号列表中设置学生或教师的班级归属。

每个班级每天（北京时间）首次打开训练时，从内置练习库随机抽取三项，保存为当天的计划。同一天刷新不会重新抽取。学生的学习总览、训练中心和“开始今日学习”共用当天计划，完成状态按学生单独保存。

对应班级的教师可在“任务管控”中添加、修改和删除当天训练。修改会清除该项原完成状态；删除后不会因为刷新自动补回。没有所属班级的学生会看到空计划提示，管理员分配班级后即可使用。

管理员账号列表展示当前存储中的未删除账号，可筛选启用状态，并可删除账号。删除会撤销登录状态并移除班级归属；为保留审计信息，后台保留不可登录的删除标记，原用户名不再开放注册。不能删除自己或最后一名启用管理员。体验模式下的删除在重启后恢复，数据库模式下持久保留。
